# Apex Motors

Apex Motors é uma página única de uma concessionária fictícia de veículos de luxo. A página apresenta um catálogo de veículos em destaque, com nome, ano, categoria, preço e imagem, e uma busca por marca, modelo e faixa de preço. Também traz uma seção com os diferenciais da loja, depoimentos de clientes e uma área de contato com formulário e informações do showroom. O projeto é desenvolvido com React, TypeScript e Tailwind CSS, com layout responsivo mobile first, como Trabalho de Conclusão de Disciplina (TCD).

## Listagens

- **Principal:** veículos em estoque (dados de um JSON externo a partir da Fase 4)
- **Secundária:** diferenciais da loja (vetor de objetos no código)
